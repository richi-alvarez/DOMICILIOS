## 📋 Implementation Checklist

### Database Schema Updates
```sql
-- Payment transactions table
CREATE TABLE payment_transactions (
  id UUID PRIMARY KEY,
  order_id UUID REFERENCES orders(id),
  stripe_payment_id TEXT,
  amount_cents INT NOT NULL,
  currency VARCHAR(3) DEFAULT 'COP',
  status TEXT NOT NULL,
  payment_method TEXT,
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);

-- Payment methods table
CREATE TABLE payment_methods (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  stripe_payment_method_id TEXT,
  card_brand VARCHAR(20),
  card_last4 VARCHAR(4),
  is_default BOOLEAN,
  created_at TIMESTAMP
);

-- Invoices table
CREATE TABLE invoices (
  id UUID PRIMARY KEY,
  subscription_id UUID REFERENCES subscriptions(id),
  stripe_invoice_id TEXT,
  amount_cents INT NOT NULL,
  status TEXT,
  due_date DATE,
  paid_at TIMESTAMP,
  created_at TIMESTAMP
);
```

### API Endpoints
```
POST   /api/payments/intents           - Create payment intent
POST   /api/orders/{id}/payments       - Process order payment
GET    /api/payments/methods           - List user payment methods
POST   /api/payments/methods           - Add payment method
DELETE /api/payments/methods/{id}      - Delete payment method
GET    /api/payments/history           - List payment history
GET    /api/invoices                   - List invoices
GET    /api/invoices/{id}/download     - Download invoice PDF
POST   /api/webhooks/stripe            - Stripe webhook receiver
```

## 🧪 Test Cases

### Payment Processing
- [ ] Free user tries to pay → blocked
- [ ] Pro user creates order → can pay
- [ ] Valid card payment → succeeds, status updated
- [ ] Invalid card payment → fails, error shown
- [ ] Payment webhook received → database updated

### Subscription Billing
- [ ] Free → Pro upgrade → subscription created
- [ ] Pro → Premium upgrade → subscription updated
- [ ] Pro → Free downgrade → subscription cancelled
- [ ] Subscription renewal → invoice generated
- [ ] Subscription payment failed → retry email sent

### Error Handling
- [ ] Network error during payment → retry UI shown
- [ ] Webhook timeout → manual retry available
- [ ] Duplicate payment attempt → idempotency key prevents double charge
- [ ] Invalid card data → clear error message
- [ ] Webhook signature invalid → rejected
